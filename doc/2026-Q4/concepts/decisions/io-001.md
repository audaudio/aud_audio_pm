# io-001: miniaudio's device layer plus native escape hatches

- Status: proposed
- Date: 2026-10-07
- Canonical source: topics/audio-io-platforms.md
- Open work: iOS is built (ticket 21): miniaudio's duplex device on an
  AVAudioSession of the backend's own, route and input changes as
  hot-plug, host times estimated from the callback, its block and the
  session's latencies. Measured on an iPad Pro (M5): the estimate misses
  the round trip by about 2 ms even with miniaudio's duplex ring buffer
  counted, and that ring buffer adds up to 27 ms of input latency - the
  RemoteIO path with hardware timestamps and the input pulled in the
  render callback is indicated (S15, or earlier for live input). Open:
  confirm on the reference iPhone; the screen-locked 4096-frame slices;
  macOS, Windows and Linux with S3b to S3d

## Decision

`aud_audio_io` wraps the low-level device API of miniaudio (public
domain / MIT-0, 0.11.x) as the common native backend for device
enumeration, hot-plug notification, full-duplex streams, channel maps,
format conversion and resampling on macOS, iOS, Windows and Linux.
Android uses Oboe directly (io-002). Where a native API buys latency or
channels that miniaudio does not expose, a dedicated backend sits next
to it behind the same interface: AUHAL with audio workgroups and
aggregate devices on macOS, `IAudioClient3` low-latency shared mode on
Windows. The web backend is our own Wasm
Audio Worklet host (web-001), not miniaudio's. Every backend fulfils the
timing contract of time-001 — presentation timestamps per callback and
latency per direction — from the native APIs where they exist and, for
miniaudio, from the platform clock read in the callback plus the device
latency queried through platform APIs. ASIO is an optional
backend in its own package under its own license.

## Why

- miniaudio is the only permissive library spanning the desktop and
  Apple platforms with enumeration, duplex and notifications; on
  Android, Oboe is the reference (io-002).
- Its web path uses ScriptProcessorNode and its worklet path was not
  functional; cubeb, SDL3, RtAudio and PortAudio lack web or Android.
- IAudioClient3 shared mode now reaches exclusive-mode latency for most
  users; ASIO's GPLv3/proprietary terms cannot enter an MIT package.
- miniaudio's callback has no timestamps, which Ableton Link needs; the
  dedicated backends deliver native ones.
