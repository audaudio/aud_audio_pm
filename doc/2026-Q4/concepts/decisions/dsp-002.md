## Decision

`aud_dsp_effects` 0.2.0 offers its effects as independent node types of
the graph, built on `AudNodeBase` against ABI 0.4: `aud.effects.freeverb`
(Jezar's Freeverb, public domain, vendored with the tunings scaled to the
sample rate), `aud.effects.plate` (Dattorro's plate of 1997, Audanika's
own code written from the paper), `aud.effects.stereo_delay` (DunneAudioKit's
StereoDelay, MIT, vendored), `aud.effects.tempo_delay` (the same delay
lines with the time from the transport's tempo and a note division),
`aud.effects.limiter` (dsp-003) and the tremolo of ticket 5. Every node
renders in place with variable blocks and ramped parameters, takes a mono
or stereo input and gives stereo (the limiter 1 to 16 channels), allocates
only in `prepare`, and reports its tail from its parameters at every
commit. `mix` is a linear crossfade in every node: 0 dry, 1 wet. Values
below 1e-15 are flushed to zero in every feedback path. Vendored files keep
their headers and say in a "Modified by Audanika" note what changed; the
notices of the package list both sources and the audit.

## Why

- The plan of ticket 17 named these sources for S10a (dsp-001): Freeverb
  and Dunne's StereoDelay are permissive, the plate is re-implemented from
  the literature because the permissive pool has no plate.
- One mix convention makes the nodes interchangeable in a chain; Dunne's
  original rendered `(1 - mix) * wet + mix * dry`, so mix 1 was dry — the
  port fixes it.
- Freeverb's `undenormalise` macro reads a float through an integer
  pointer, undefined behaviour under strict aliasing; the add-and-subtract
  trick against denormals rounded tiny values up and kept the plate's
  feedback cycling at about 1e-25 for ever, so a comparison flushes them.
- Separate nodes let an app build its own chain: on a channel, on a branch
  through gain nodes, or on the sum.

## Consequences

- The Dart API of the spike breaks: `AudDspEffects.register` is the native
  function for `AudNativeNodePackage`, `registerWith` takes an
  `AudHostApi` pointer; the ids live in `AudFreeverb`, `AudPlateReverb`,
  `AudStereoDelay`, `AudTempoDelay`, `AudLimiter`, `AudTremolo`.
- `AudEffectsBench` in `testing.dart` measures the render time of a node
  on the calling thread, since the engine times only whole blocks.
- license-003's audit for `aud_dsp_effects`: no Faust-generated code, no
  Soundpipe module, nothing under the LGPL or the GPL.
