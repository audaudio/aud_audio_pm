# app-007: A sample set exists once in the app's content, as FLAC, and presets include it

- Status: accepted
- Date: 2026-10-19
- Canonical source: tickets/2026-10-14-32-share-sample-sets-between-sfz-presets.md,
  done as part of tickets/2026-10-14-31-port-soundprism-js-lfo-presets.md
  (the user's decision of 2026-10-18)
- Refines: [app-001](app-001.md) — the layout and the format of the
  converted content
- Open work: none

## Decision

`content/sfz` holds every sample set once:
`samplesets/<id>/samples/NNN.flac`, `regions.sfz` with only its regions
(roots, keys, loops) and an `instrument.sfz` that plays it alone. The CC 7
curve, the velocity curve and the legacy level live once in
`common/legacy-engine.sfz`. A preset names its set with `#define $SET <id>`,
includes the common block first, then sets `default_path` and the
transposition as `note_offset=-t` with `note_offset_open_bounds=on`
(sampler-010) in a `<control>`, then its `<group>`, then includes the
set's regions. Both converters, `convert-content-bundle.js` and
`convert-soundprism-link-edition.js`, write this layout through
`tool/sfz-layout.js`, which validates every include, sample and key. The
samples are FLAC, encoded by macOS's `afconvert` and decoded back to check
every frame; Android stores them uncompressed in the APK. The old presets
render the same bit for bit as with the WAV copies.

## Why

- A loop point fixed in a set reaches every preset that plays it; a
  preset file shows only what makes it a preset.
- FLAC keeps every frame and halves the WAVs; the combis' sets, decoded
  from AAC, take 105 MB as FLAC (the user accepted the size on
  2026-10-19).
