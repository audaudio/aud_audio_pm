# osc-001: Every node has an OSC address

- Status: proposed
- Date: 2026-10-07
- Canonical source: topics/osc-addressing.md (R10)
- Open work: fix the address grammar and the reply vocabulary in the
  core ticket

## Decision

Graphs, nodes, inlets, outlets and parameters carry OSC 1.1 addresses
(`/graph/<id>/node/<id>/param/<name>` and the like, with `*`, `?`,
`[]`, `{}` and `//` patterns). One message model — address, typed
arguments, timetag — serves the Dart API, the Dart–C++ command queue,
the sequencer's events and an optional network server in
`aud_audio_osc`. Timetags map to sample positions: immediately, absolute
host time, or beat time through the transport. The engine replies and
notifies in the SuperCollider manner (`/done`, `/fail`, node lifecycle,
meters).

## Why

- OSC is the brief's model; sfizz already speaks it; SuperCollider shows
  it scales to a whole synthesis server.
- One addressing scheme lets the graph editor, the sequencer, remote
  controllers and tests speak the same language.
